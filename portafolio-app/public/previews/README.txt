Instrucciones para añadir las capturas de pantalla de tus proyectos:

Guarda tus imágenes en esta carpeta (portafolio-app/public/previews/) con los siguientes nombres:

1. trazabilidad-qr.png  -> Para la "Aplicación Web de Gestión de Inventario y Trazabilidad por QR"
2. sitoinformatic.png    -> Para "SitoInformatic | Plataforma eCommerce y Configurador"
3. automatizacion-datos.png -> Para "Desarrollador de Soluciones de Automatización"
4. coanda-forms.png     -> Para "Assistant Virtual de Recomendación Inteligente"

En cuanto coloques una imagen con alguno de estos nombres en esta carpeta, el botón de "Vista previa" la mostrará automáticamente en el portafolio web.
